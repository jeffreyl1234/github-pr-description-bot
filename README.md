# GitHub PR Description Bot

A GitHub App that automatically generates pull request descriptions using Claude AI. When a PR is opened, the bot reads the diff and commit messages, sends them to Claude, and posts a structured description as a comment — without touching what the author wrote.

## How It Works

```
PR opened on GitHub
       ↓
POST /api/webhook  (Vercel serverless function)
       ↓
Verify HMAC-SHA256 webhook signature
       ↓
Fetch diff (up to 8,000 chars) + commit messages via Octokit
       ↓
Claude Sonnet generates a markdown PR description
       ↓
Bot posts it as a comment on the PR
```

## Features

- **Zero config for contributors** — just open a PR, the description appears automatically
- **Non-destructive** — posts as a comment, never overwrites what the author wrote
- **Handles large PRs** — diffs over 8,000 characters are truncated gracefully
- **Stateless** — no database, no persistent state, pure serverless
- **Secure** — validates every webhook with HMAC-SHA256 before processing

## Stack

- **Runtime:** Node.js on Vercel serverless functions
- **GitHub API:** [@octokit/app](https://github.com/octokit/app.js) for GitHub App authentication
- **AI:** [Claude Sonnet](https://anthropic.com) via `@anthropic-ai/sdk`

## Setup

### 1. Create a GitHub App

Go to **GitHub → Settings → Developer Settings → GitHub Apps → New GitHub App**.

- **Webhook URL:** `https://your-vercel-deployment.vercel.app/api/webhook`
- **Webhook secret:** generate a random secret and save it
- **Repository permissions:**
  - `Pull requests: Read & Write`
  - `Contents: Read`
- **Subscribe to events:** `Pull request`

After creating, generate and download a **private key** (`.pem` file).

### 2. Get Your Environment Variables

| Variable | How to get it |
|---|---|
| `GITHUB_APP_ID` | Shown on your GitHub App's settings page |
| `GITHUB_PRIVATE_KEY` | Base64-encode the downloaded `.pem`: `base64 < private-key.pem` |
| `WEBHOOK_SECRET` | The secret you set in step 1 |
| `ANTHROPIC_API_KEY` | From [console.anthropic.com](https://console.anthropic.com) |

### 3. Deploy to Vercel

```bash
npm install -g vercel
vercel --prod
```

Set the four environment variables in the Vercel dashboard under **Project → Settings → Environment Variables**.

### 4. Install the GitHub App

Go to your GitHub App's settings page and click **Install App**. Select the repos you want the bot to run on.

That's it — open a PR on an installed repo and the bot will comment within a few seconds.

## Local Development

Use [smee.io](https://smee.io) to proxy GitHub webhooks to your local machine.

```bash
# Install dependencies
npm install

# Install smee client
npm install -g smee-client

# Copy and fill env vars
cp .env.example .env.local

# Start smee proxy (replace with your smee channel URL)
smee --url https://smee.io/YOUR_CHANNEL --target http://localhost:3000/api/webhook &

# Run locally
vercel dev
```

Set the smee URL as the webhook URL in your GitHub App settings while developing.

## Project Structure

```
├── api/
│   └── webhook.js      # Vercel entry point — signature verification + routing
├── lib/
│   ├── github.js       # GitHub App auth (Octokit) + post comment helper
│   ├── diff.js         # Fetch raw diff, truncate, extract filenames + commits
│   └── claude.js       # Build prompt and call Claude API
├── vercel.json         # Sets 30s function timeout
├── .env.example        # Documents required environment variables
└── package.json
```

## Notes

- The bot only fires on `pull_request: opened` — it won't re-run on every push to the branch
- If Claude returns an error or empty output, the bot silently skips posting (no noisy failure comments)
- `maxDuration: 30` in `vercel.json` requires Vercel Pro; on the free Hobby plan the limit is 10s (Claude Sonnet typically responds in 2–4s so it usually works either way)
